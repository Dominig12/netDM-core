# Разделение контрактов netDM

Wire-контракты группируются по доменам в `src/NetDM.Services/Contracts`. Встроенные контракты по-прежнему создаются через `SchemaRegistry.CreateDefault()` в прежнем порядке; ABI и состав схем не меняются.

Для новой независимой механики создайте собственную реализацию `IServiceContractModule`, регистрирующую `SchemaDefinition` и команды через `Register`/`RegisterCommand`. Передайте список дополнительных модулей в `SchemaRegistry.CreateDefault(extensions)` при сборке Host. Таким образом расширения не должны менять `Schemas.cs` и соседние домены. Не регистрируйте модули после создания `ServiceRuntime`: реестр должен быть полностью сформирован до запуска сессии.

Это первый этап разделения **контрактов**; обработчики Host-команд и IPC-пути остаются прежними. Для полного плагинного API далее потребуется зарегистрировать реализации обработчиков в Host через DI и маршрутизатор, не выполняя произвольные DM-процедуры из сетевых пакетов.

Сохраняйте строгую валидацию полей, версионирование, ограничения длины и проекции. Один домен не должен заменять контракт другого: дубликаты отклоняются.
